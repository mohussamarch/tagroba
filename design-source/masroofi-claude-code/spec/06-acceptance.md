# 06 — اختبارات القبول

حوّل الحالات التالية إلى اختبارات فعلية للمنطق وقاعدة البيانات، ثم اختبارات واجهة للأجزاء الحرجة. لم يُنفذ Android بعد؛ هذه حالات متوقعة وليست تقرير نجاح تطبيق.

| الحالة | النتيجة المتوقعة |
|---|---|
| fixture الأساسي: دخل 7000 + البيك32 + Amazon720 + كاش100 | دخل7000، مصروف852، متبقي6148، دون احتساب قرض/أمانة/نقل داخلي |
| وضع وسم هدية وتسوق على Amazon720 | مبلغ واحد720، لا1440 ولا2160 |
| ربط البيك32 كاملًا بعبد الفتاح كدين | المصروف الأساسي ينخفض من852 إلى820؛ لك عنده32 |
| تحصيل32 منه | لك عنده0؛ الدخل يبقى7000؛ المصروف820 |
| تخصيص20 فقط من فاتورة32 لشخص | المصروف ينخفض20، ويبقى12 عليك |
| اختيار هدية لشخص | المصروف كامل؛ لا التزام عليه |
| قرض مستلم500 | السيولة+500؛ الدخل لا يتغير؛ له عندك500 |
| أمانة مستلمة200 | السيولة+200؛ الدخل لا يتغير؛ أمانة200 منفصلة عن القرض |
| سداد قرض300 | دينك ينخفض300؛ المصروف لا يتغير |
| محاولة رد أمانة300 والمتاح200 | رفض مع تفسير؛ لا السحب من رصيد قرض ضمنيًا |
| سداد أكبر من الدين | رفض أو تقسيم صريح إلى تسوية وأمانة؛ لا رصيد سالب صامت |
| تحويل500 بين البنك والكاش | رصيد البنك−500، الكاش+500؛ دخل/مصروف دون تغير |
| صرف100 كاش لاحقًا | الكاش−100، المصروف+100؛ شارة كاش في كل العروض |
| تحويل عبر برق لحسابي في مصر | حركة داخلية؛ لا مصروف1000 أو دخل1000 |
| تغيير غرضه إلى دعم | مصروف1000 مرة واحدة |
| رسوم20 ضمن خصم1020 | أصل1000+رسوم20؛ لا إجمالي1040 |
| عملة وصول مختلفة مجهولة القيمة | غير متاحة، لا1:1 ولا جمع EGP مع SAR |
| دخل0 | الادخار غير متاح؛ لاInfinity/NaN |
| مصروف أعلى من الدخل | متبقي ونسبة سالبان واضحان |
| مجموع الفروع | يساوي إجمالي الأصل مرة واحدة |
| دمج/أرشفة تصنيف | السجل والمبلغ محفوظان، القواعد والسقوف تُعالج، والتراجع متسق |
| فبراير2028 ويوم راتب31 | حدود الفترة صحيحة وقابلة للعرض؛ لا يوم31 فبراير |
| فترة لا بيانات فيها | صفر عمليات؛ لا استعمال أرقام شهر آخر |
| تصنيف بلا سقف/تاريخ | لا سقف أو متوسط مخترع ولا تنبيه عتبة |
| إعادة نفس CSV مرتين | عدد العمليات والتأثير المالي ثابتان |
| repeated-import.csv | مرجع جديد واحد، ومكرر مؤكد واحد، ومتشابه واحد يحتاج قرارًا |
| نفس المرجع من حسابين مختلفين | لا إسقاط أحدهما باعتباره مكررًا تلقائيًا |
| مرجع موجود بمبلغ متغير | تعارض يمنع الكتابة الصامتة |
| انقطاع أثناء حفظ دفعة | صفر أو كامل الدفعة، لا نصفها |
| رسالة وكشف للعملية نفسها | سجل اقتصادي واحد ومصدران |
| ترتيب يوم مجهول في مطابقة الرصيد | توضيح الغموض؛ لا ادعاء تحديد أول فرق يقينًا |

| صف مبلغ أو تاريخ فاسد | رقم الصف ورسالة، دون فقد المدخلات |

| مصدر سعر غير متاح | آخر سعر مع التاريخ أو غير متاح؛ لا صفر سوقي مختلق |
| بيع أصل جزئي | الكمية والتكلفة المتبقية والربح المحقق صحيحة؛ لا دخل من كامل الحصيلة |
| إعادة فتح التطبيق | العمليات والديون والثيم محفوظة |
| نسخة احتياطية ثم استعادة | كل العلاقات والمعرفات والمجاميع نفسها بلا تكرار |

| TalkBack ومظهران | تسميات الأيقونات والمبالغ واتجاهها مقروءة |

## قبل تسليم APK
بناء ناجح من الكود المسلم، اختبار هجرات وحسابات ودقة هللات، تشغيل على محاكي أو جهاز مع توضيح أيهما، تثبيت/إغلاق/إعادة فتح، واختبار تصدير واستعادة. لا تسجل اجتياز اختبار الجهاز إن لم يتوفر S24 Ultra فعليًا. وثق حالات PDF/SMS والأسعار غير المدعومة بدل وضعها في قائمة المكتمل.
