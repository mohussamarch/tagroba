# بيانات الاختبار

كل أحداث ledger-cases.json وملفات CSV مصطنعة ولا تمثل كشف المستخدم. القيم في JSON بالهللة، وCSV بالريال.

baseline.csv يختبر الاستيراد الأولي. التصنيف الاقتصادي الدقيق ووجهة التحويل وربط الشخص في ledger-cases.json يكملان أعمدة CSV المحدودة؛ لا تفترض أن transfer يعني تلقائيًا تحويلًا داخليًا. أكد هذه الأنواع في مرحلة المراجعة قبل توقع رصيد قرض وأمانة.

بعد baseline: repeated-import.csv يحتوي عملية مؤكدة التكرار، وجديدة44 ريال، ومتطابقة التفاصيل دون مرجع تحتاج مراجعة. أضف الجديد فقط: المصروف896 والدخل7000. conflict.csv مرجع موجود بمبلغ مختلف. invalid.csv صفان غير صالحين يجب رفضهما.

merchant-reference.json وrule-reference.json مرجع أسماء/تصنيفات من ملفات العمل السابقة وليسا معاملات مصطنعة أو كشفًا بنكيًا. أسماء التجار وثقتهم لا تثبت هوية متجر غامض. لا توجد أرقام حسابات أو مجاميع معاملات في هذين الملفين.
